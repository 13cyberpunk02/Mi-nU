# Mi`nU

Мессенджер для Android и Windows на .NET MAUI с сервером на ASP.NET Core. Текстовые чаты работают через SignalR, а голосовые и видеозвонки — через [13CyberPunk02.Maui.WebRTC](https://www.nuget.org/packages/13CyberPunk02.Maui.WebRTC).

> Статус: ранняя разработка. Звонки соединяются, только когда устройства видят друг друга напрямую, например в одной локальной сети: серверов STUN и TURN пока нет.

## Возможности

- Регистрация и вход по логину и паролю
- Личные и групповые чаты, поиск людей по логину или имени
- Доставка сообщений в реальном времени и постраничная история
- Повторная отправка неотправленного сообщения без дублей
- Голосовые и видеозвонки один на один с экраном входящего вызова, пока приложение открыто
- Групповые звонки до 4 участников, где каждое устройство соединяется с остальными напрямую

### В планах

- Звонки через интернет
- Входящие звонки и уведомления при закрытом приложении
- Счётчики непрочитанных и управление группами

## Запуск

Нужны .NET 10 SDK, рабочие нагрузки .NET MAUI и Docker.

Выполните команды из корня репозитория. Первая запускает PostgreSQL для разработки, а вторая — сервер, который в окружении `Development` сам применяет миграции базы:

```powershell
docker compose -f server/docker-compose.yml up -d
dotnet run --project server/MinU.Server --urls http://0.0.0.0:5199
```

Затем запустите приложение из Visual Studio или из другого терминала:

```powershell
dotnet build 'Mi`nU.csproj' -t:Run -f net10.0-windows10.0.19041.0
```

Одинарные кавычки обязательны: в PowerShell обратный апостроф служит символом экранирования.

### Подключение телефона

Отладочная сборка по умолчанию подключается к `http://127.0.0.1:5199`, а на экране входа есть поле для смены адреса.

- **По USB** пробросьте порт:
  ```powershell
  adb reverse tcp:5199 tcp:5199
  ```
- **По Wi-Fi** укажите адрес компьютера, например `http://192.168.0.80:5199`, и разрешите порт 5199 в брандмауэре.

## Тесты

Для тестов нужен контейнер PostgreSQL из раздела выше. Каждый запуск создаёт и удаляет собственную базу:

```powershell
dotnet test server/MinU.Server.Tests
```

## Перед развёртыванием

Сервер и приложение в текущем виде не готовы к работе в продакшене:

- Задайте в `Jwt:Key` свой секрет не короче 32 символов, а в `ConnectionStrings:Default` — свою базу. Не используйте значения из `appsettings.Development.json`.
- Задайте `Database:MigrateOnStartup` в `true` или применяйте миграции сами: вне `Development` по умолчанию они не запускаются.
- Используйте HTTPS и укажите адрес сервера в `AuthService`: в релизной сборке нет поля адреса, а Android 9 и новее блокирует в ней обычный HTTP.
- Запускайте только один экземпляр сервера: текущие звонки хранятся в памяти.
