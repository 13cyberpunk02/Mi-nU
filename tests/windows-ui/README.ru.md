# Проверки интерфейса на Windows

Сквозные проверки Windows-приложения. Каждая запускает отладочную сборку, входит новым тестовым пользователем и управляет
приложением через UI Automation, пока второй тестовый пользователь действует через сервер: пишет, шлёт фото, голосовые и
кружки, звонит. Они ловят то, чего не поймают модульные тесты, — что экраны после правки по-прежнему работают вместе.

## Запуск

```powershell
powershell -ExecutionPolicy Bypass -File tests\windows-ui\run-all.ps1
```

Скрипт собирает приложение и оба вспомогательных инструмента, поднимает базу и хранилище из `server\docker-compose.yml`,
запускает сервер на `http://127.0.0.1:5199` в режиме Development (если там ещё никто не отвечает), прогоняет все проверки и
печатает по строке на каждую. Если хоть одна упала, код выхода — 1.

- `-NoBuild` — без сборки, если приложение уже собрано.
- `-Only voice-check,layout-check` — только указанные.
- Одна проверка отдельно: `powershell -ExecutionPolicy Bypass -File tests\windows-ui\voice-check.ps1` (сервер должен работать).

Нужны Docker Desktop, .NET 11 SDK и `ffprobe` (из FFmpeg) для проверок записи.
Полный прогон идёт около получаса. **Компьютер в это время не трогать:** проверки щёлкают и печатают, открывают диалог
выбора файла и записывают несколько секунд с микрофона и камеры — эти записи уходят только на локальный сервер.

## Что здесь

| Файл | |
|---|---|
| `common.ps1` | Пути, тестовые пользователи и помощники, которыми пользуются все проверки |
| `*-check.ps1`, `photo-hang.ps1` | Сами проверки, по одной функции в каждой; первая строка говорит, что проверяется |
| `run-all.ps1` | Запуск всех |
| `tools/sender` | Собеседник в чате: шлёт сообщения, файлы, голосовые и кружки, звонит, отвечает |
| `tools/peer` | Настоящий участник звонка через 13CyberPunk02.Maui.WebRTC — для проверок, где нужны звук и видео |
| `assets/` | Что отправляют проверки: фото 3000×2000 с выдуманной меткой в EXIF, картинка, голосовое и кружок |
| `dialogs.cs` | Находит системный диалог выбора файла, который в Windows 11 живёт в отдельном процессе |

## Как написать проверку

Начните с комментария о том, что она проверяет, затем `$prefix='xx'; . "$PSScriptRoot\common.ps1"` со своими двумя буквами.
Ищите элементы по `AutomationId`, отмечайте результат через `Check 'что' (условие)`, ждите через `Until { ... } секунды`,
а в конце вызовите `Summary`. Сохраняйте в UTF-8 **с BOM**: иначе Windows PowerShell 5.1 неверно прочтёт русский текст.
